## 📊 Portfolio Projects

### Python
- **[Analyzing the Impact of Smoking on Oral Health](#)**  
  *Goal:* Examine the association between smoking behavior and oral health status using NHANES data.  
  *Skills:* Data wrangling, supervised classification, feature engineering, data balancing, model tuning.  
  *Tech:* Python, Scikit-learn, Random Forest, Boosting, OneHotEncoder, SMOTE  
  *Highlights:* Merged and preprocessed NHANES data, addressed class imbalance with Random Oversampling, evaluated model performance with Random Forest and Boosting (misclassification ~0.30), and identified “age started smoking” and “cigarette frequency” as key predictors of poor oral health.

- **[Predicting Hypertension from Lifestyle and Health Factors](#)**  
  *Goal:* PInvestigate the relationship between high cholesterol and hypertension while controlling for behavioral and dietary variables using NHANES data.
  *Skills:* Logistic regression with regularization, feature selection, grid search, classification evaluation.
  *Tech:* Python, Scikit-learn, Pandas, Matplotlib, Lasso (L1) Regularization
  *Highlights:* Merged 6 NHANES datasets, cleaned and one-hot encoded categorical predictors, built a logistic regression model with L1 regularization, and tuned it using grid search with cross-validation. Identified high cholesterol and chest pain as top predictors of hypertension, achieving ~64% accuracy on test data.

### SAS
- **[Assessing the Impact of Bariatric Surgery on BMI](#)**  
  *Goal:* Evaluate how different types of bariatric surgery (LAGB, RYGB) impact patients' BMI over time, while accounting for comorbidities and behavioral factors.  
  *Skills:* Longitudinal data analysis, statistical inference, generalized linear models (GLM), interpretation of regression outputs. 
  *Tech:* SAS
  *Highlights:*Analyzed BMI trends over time post-surgery using a GLM framework. Found that both LAGB and RYGB treatments significantly reduced weight compared to control. Also assessed the role of comorbidities (diabetes, hypertension) and alcohol consumption, finding time as a significant predictor of weight loss, while gender, diabetes, and hypertension had no statistically significant effects
